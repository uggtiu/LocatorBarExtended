# Extended Locator Bar

Клиентский мод для Minecraft, расширяющий стандартный **Locator Bar** (панель локатора), добавленный в Minecraft 1.21.6.

Вместо стандартных цветных кружков/квадратов мод отображает на панели локатора **головы игроков** и их **ники** над иконками — чтобы сразу видеть, кто где находится, не наводя курсор и не запоминая цвета.

## Возможности

- 🎯 Замена цветных иконок игроков на их головы (рендер из скина, как в таб-листе)
- 🏷️ Отображение никнейма прямо над иконкой на панели локатора
- 🔄 Полная совместимость со стандартным поведением ванильного Locator Bar (расстояние, направление, скрытие через sneak/тыкву/невидимость/spectator по-прежнему работают)

## Установка

1. Убедитесь, что установлен [Fabric Loader](https://fabricmc.net/) и [Fabric API](https://modrinth.com/mod/fabric-api) для вашей версии Minecraft.
2. Скачайте `.jar` мода и поместите его в папку `mods` вашей клиентской установки.
3. Запустите игру через профиль Fabric.

## Совместимость

Мод работает **только на клиенте** и не требует установки на сервер — вся логика построена на перехвате и переотрисовке уже получаемого клиентом waypoint-пакета Locator Bar (`ClientboundTrackedWaypointPacket`).

На серверах, где Locator Bar отключён администратором (`/gamerule locatorBar false`), мод не будет отображать ничего — так же, как и ванильный клиент.

## Как это работает (кратко)

Мод перехватывает данные waypoint'ов игроков (UUID, позиция/направление, стиль иконки), которые сервер и так присылает клиенту для отрисовки Locator Bar, и заменяет стандартный рендер иконки на:

- голову игрока, полученную из уже закешированного клиентом скина (через данные таб-листа);
- никнейм, отрисованный текстом чуть выше иконки.

Никакие дополнительные данные с сервера не запрашиваются — используется только то, что уже передаётся в рамках ванильного протокола Locator Bar.

## Известные ограничения

- Если сервер передаёт только направление (`Azimuth`) без точных координат, мод не может показать больше информации, чем передал сервер — сама механика точности осталась ванильной.
- Игроки, скрытые от Locator Bar (sneak, тыква/голова моба, невидимость, spectator), по-прежнему не отображаются — мод не обходит эту защиту.
